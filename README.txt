MAKALOKA BEACH RESORT WEBSITE — UPDATED PACKAGE

Includes: responsive website, Our Story section, booking inquiry form, QR code, installable PWA manifest/icons, and basic service worker.

BOOKING FORM: The form opens WhatsApp with the guest details pre-filled to the resort number. The guest must press Send in WhatsApp. This is an inquiry only; it does not automatically confirm a reservation.

QR CODE: images/makaloka-website-qr.png points to https://makalokabeachresortwebsitephotosrea.vercel.app/

DEPLOY: Extract this ZIP and upload/replace all files in your GitHub repository, keeping the directory structure. Vercel should redeploy automatically. After deployment, test the booking form and QR code on a phone.

For the installable mobile-app experience, use HTTPS hosting and visit the site in a supported browser, then select Add to Home screen / Install app.

OCEAN SOUND UPDATE
- Homepage hero now uses the resort beachfront photo for a shoreline feel.
- Tap “Play Ocean Sounds” to hear a gentle looping surf ambience. Browsers require a user tap before sound can start; audio is off by default. Tap “Stop Ocean Sounds” to stop it.
- The ocean ambience file is included at audio/ocean-waves.wav.

SOUND STYLE: Gentle waves rolling onto a sandy shore, softened for quiet background listening.
